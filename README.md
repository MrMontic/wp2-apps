### Что нужно для установки
Чтобы запускать `.wp2app` на часах, понадобятся две вещи:
1. **Прошивка и App Loader** с сайта **[fmc.tools](https://fmc.tools)** — установи патченую прошивку и App Loader на свои **CMF Watch Pro 2** по инструкции на сайте.
2. **[WP2 Sideloader](https://github.com/MrMontic/wp2-sideloader)** — автономное Android-приложение для загрузки `.wp2app` на часы прямо с телефона по Bluetooth (без ПК).

### Как установить на часы
1. Убедись, что на часах стоят патченая прошивка и **App Loader** с [fmc.tools](https://fmc.tools).
2. Установи **[WP2 Sideloader](https://github.com/MrMontic/wp2-sideloader/releases/latest)** на телефон (Android 12+).
3. Скачай нужные `.wp2app` файлы из таблицы выше или со страницы **[Releases](https://github.com/MrMontic/wp2-apps/releases/latest)**.
4. Открой **WP2 Sideloader**, подключись к часам, выбери `.wp2app` и нажми **Установить** — приложение сразу появится в **Custom Apps** на часах.

### Requirements
1. **CMF Watch Pro 2** running the community patched firmware & **App Loader** from **[fmc.tools](https://fmc.tools)**.
2. **[WP2 Sideloader](https://github.com/MrMontic/wp2-sideloader)** on Android (12+) to sideload `.wp2app` packages over Bluetooth without a PC.

### Quick Start
1. Make sure your watch has the patched firmware and **App Loader** from [fmc.tools](https://fmc.tools).
2. Install **[WP2 Sideloader](https://github.com/MrMontic/wp2-sideloader/releases/latest)** on your Android phone.
3. Download any `.wp2app` package from the table above or from **[Releases](https://github.com/MrMontic/wp2-apps/releases/latest)**.
4. Open **WP2 Sideloader**, connect to your watch, pick the `.wp2app` file, and tap **Install**.

## 🛠️ Сборка из исходников / Build from Source

All apps are written in `no_std` **Rust** (`thumbv7em-none-eabi`) on top of the community **`cmf-watch-sdk`**.
To build from source, place any folder from `apps/` into `cmf-watch-sdk/sdk/examples/`, register it in `sdk/Cargo.toml`, and pack it with `wp2apps pack` using the matching icon from `assets/icons/`.
